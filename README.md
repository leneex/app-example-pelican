# Pelican

Пример статического сайта на [Pelican](https://getpelican.com/), который можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Статический сайт — сборка Railpack |
| Одностраничное приложение (SPA) | выключено |
| Путь до директории проекта | `/` |
| Директория сборки | `/output` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | `pelican content` |
| Путь проверки состояния | `/` |

Порт указывать не нужно: статический сайт отдаётся на порту 80. Railpack видит
`requirements.txt` и ставит Pelican, команда сборки кладёт готовые страницы в `output`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# виртуальное окружение и зависимости
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt

# запуск в режиме разработки
pelican --autoreload --listen

# сборка для продакшн
pelican content
```

Нужен Python 3.10 или новее.
